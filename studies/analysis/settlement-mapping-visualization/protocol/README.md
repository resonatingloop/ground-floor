# cold-analysis protocol

the primary agent is the builder and run steward, never the cold analyst.

the builder freezes stage a and stage b before spawning at least one sub-agent
without inherited conversation. the analyst receives only stage a. its complete
return is preserved and fingerprinted before the same analyst receives stage b.
raw returns remain distinct from the steward-authored concordance.

a run is contaminated when roles collapse, forbidden files are opened, stage b
is revealed before stage a is preserved, the packet changes after contact, or
the analyst is coached between stages. contaminated returns remain evidence of
protocol behavior but cannot satisfy the required cold run.

packet isolation is procedural rather than a filesystem security boundary.
“cold” means conversation-independent and packet-bounded, not priorless.
