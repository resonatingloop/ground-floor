# data boundary

`fixtures/` contains fictional examples from the historical, unadopted event
ledger prototype. it is not evidence for the current study.

private source conversations, screenshots, exports, and local corpora remain in
their existing private locations. if a temporary local working copy is
necessary, use `private/` or `raw/`; both paths are ignored by git.

do not move source messages into a tracked fixture merely to make the analysis
portable. public research artifacts may contain:

- opaque local evidence references;
- derived annotations that do not reconstruct private wording;
- explicitly marked synthetic traces; or
- quotations separately cleared by the owner for publication.

the ignored root-level collab-session export is retained locally for analysis.
its presence is not publication authority.
